# Contributing

Short version:

- Branches: `chore/`, `feat/`, `fix/`, `docs/` prefixes.
- Commits: Conventional Commits — `type(scope): summary`.
- PRs go to `develop` (never push to `main`), reference the linked issue in the title,
  and require green CI (ruff check + pytest) plus a teammate review before merging.

Full details: [docs/contributing.md](docs/contributing.md).
